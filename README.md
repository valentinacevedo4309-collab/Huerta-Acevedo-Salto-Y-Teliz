## 📌 ¿De qué trata el proyecto?

Este proyecto consiste en el desarrollo e implementación de un sistema web para el monitoreo, automatización y cuidado integral de una **Huerta Escolar**. 

El sistema integra tecnología basada en sensores que permiten registrar variables clave en tiempo real:
- **Monitoreo de Humedad:** Mide la cantidad de agua en la tierra para activar automáticamente el sistema de riego cuando el sustrato se seca.
- **Sensor de pH:** Controla los niveles de acidez del suelo para garantizar las condiciones idóneas de cada cultivo.
- **Protección Anti-Heladas:** Detecta temperaturas extremas o congelamiento y activa un ciclo de riego programado para descongelar y proteger los tejidos de las plantas.

## 🚀 ¿Qué agrega esta página web?

El sitio web está desarrollado con **HTML5, CSS3 y JavaScript**, estructurado en varias secciones e interacciones:

1. **Navegación Estructurada (`<nav>`):** Sistema de menú que conecta fluidamente la página principal (`index.html`) con el calendario (`calendario.html`).
2. **Calendario Mensual Interactivo:** Segunda pestaña del sitio que permite seleccionar cualquier día del mes para escribir y visualizar tareas de siembra directamente en la cuadrícula de fechas.
3. **Consulta de Riego por JavaScript:** Botón interactivo que procesa la información de la huerta e imprime el cronograma de riego en la consola del navegador.
4. **Fichas Técnicas de Cultivos y Tecnología:** Secciones visuales en cuadrícula (*Grid*) con información sobre las especies plantadas (tomate, lechuga, albahaca, etc.) y los componentes electrónicos utilizados.
5. **Diseño Responsive:** Maquetación adaptable mediante *@media queries* para garantizar que el sitio se vea correctamente en celulares, tablets y computadoras.
6. **Optimización y SEO:** Configuración de metadatos (`<title>` descriptivo, `<meta name="description">`, `meta viewport`) y favicon personalizado con el ícono del brote (`🌱`).
